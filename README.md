# Panel de Administración de Estudiantes (Frontend)

Esta es la aplicación frontend (SPA) para la gestión de estudiantes, construida con Angular.

## Tecnologías Utilizadas

- **Frontend**: Angular 17+, Angular Material
- **Estado**: Listo para conectar a una API de backend.
- **Modo de Desarrollo**: Incluye datos de prueba (mocks) para funcionar de forma independiente.

---

### 1. Prerrequisitos
- Node.js (v18 o superior)
